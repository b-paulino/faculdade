# Introdução ao HTML

O objetivo desta pasta é documentar todas as aulas da disciplina
de desenvolvimento Front-end.

## Pré-requisitos

* **Navegador Web:** Google Chrome, Firefox, Edge ou Opera
* **Editor de Código:** Visual Studio Code (VS Code)
* **Extensão do VS Conde:** *Live Server* para rodar o código localmente com recarregamento autómatico

### Passo a passo para instação

Siga as intruções abaixo caso queira clonar o repositorio e rodar ele localmente:

1. git clone https://github.com/b-paulino/faculdade.git
2. cd faculdade
